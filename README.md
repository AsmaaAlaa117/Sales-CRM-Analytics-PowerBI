# Sales & CRM Analytics - Power BI

## Project Overview

This project presents a collection of Power BI dashboards developed to analyze sales performance, CRM activity, opportunity management, forecasting, bookings, cancellations, and registration progress.

The dashboards were designed to transform commercial and CRM data into clear and actionable insights, helping users monitor performance, identify data quality issues, track progress, and support business decision-making.

> **Note:** The screenshots included in this repository have been anonymized to protect confidential business information. The original Power BI files and underlying datasets are not included.

---

## Dashboards

### 1. CRM Progress Dashboard

The CRM Progress Dashboard provides an overview of CRM activity and sales pipeline progress.

It includes:

- Open quotations
- Open opportunities
- Quoted accounts
- Opportunity and forecast pools
- End-user project status
- Inquiry status
- Quotes created during the month
- Closed-won quotations
- Closed-lost quotations
- CRM utilization indicators
- Activity by division and country

![CRM Progress Dashboard](CRM%20Progress.png)

---

### 2. Opportunity Validation Dashboard

This dashboard was developed to monitor opportunity records and support CRM data quality and validation.

It includes:

- Total opportunities
- Unique records
- Duplicate records
- Updated records
- Records under review
- Records pending validation
- Monthly record update status
- Opportunities by division
- Opportunity creation trends
- Team contribution
- Project and revenue analysis

The dashboard also provides filters for opportunity status, validation status, team, region, and sales specialist.

![Opportunity Validation Dashboard](Opportunity%20Validation.png)

---

### 3. Registrations Analysis

The Registrations Analysis dashboard tracks registration activities across different years, business units, accounts, and sales managers.

It includes:

- Total registrations
- Current-year registrations
- Registration status
- Historical registration trend
- Monthly registration activity
- Registrations by business unit
- Registrations by sales manager
- Account-level registration details

Interactive filters allow the analysis to be viewed by year, business unit, sales manager, and account.

![Registrations Analysis](Registration%20analysis.png)

---

### 4. Net Bookings Dashboard

The Net Bookings Dashboard provides a detailed view of sales booking performance.

It includes:

- Budget
- Net booked value
- Budget achievement %
- Cancellation value
- Net bookings by sales manager
- Net bookings by country
- Net bookings by sector
- Net bookings by region
- Net bookings by account
- Net bookings by project
- Net bookings by end user

This dashboard helps compare actual booking performance against budget and identify the main contributors to net bookings.

![Net Bookings Dashboard](Netbooking.png)

---

### 5. Cancellations Dashboard

The Cancellations Dashboard focuses on analyzing cancelled sales and identifying the main sources and reasons for cancellations.

It includes:

- Total booked value
- Cancelled value
- Net booked value
- Cancellations by sales manager
- Cancellations by sector
- Cancellation reasons
- Cancellations by project
- Cancellations by account
- Cancellations by end user
- Projects without recorded cancellation reasons

The dashboard supports identifying cancellation patterns and areas requiring further investigation.

![Cancellations Dashboard](Cancellation.png)

---

### 6. Forecast Health Check

The Forecast Health Check dashboard provides a forward-looking view of sales performance against budget.

It includes:

- Annual budget
- Net booked value
- Budget achievement %
- Remaining forecast
- Projected budget achievement
- Sales booking forecast timeline
- Forecasted opportunities
- Forecasted inquiry status
- Remaining opportunities

The dashboard combines actual bookings with forecasted opportunities to provide visibility into expected year-end performance.

![Forecast Health Check](Forecast%20Health%20Check.png)

## Key Business Questions

These dashboards were designed to help answer questions such as:

- How is current sales performance tracking against budget?
- What is the expected year-end performance based on the current forecast?
- Which opportunities are contributing to the sales pipeline?
- How complete and reliable is the CRM opportunity data?
- Where are duplicate or unvalidated CRM records?
- What are the main reasons for sales cancellations?
- Which sectors, regions, accounts, and projects contribute to bookings?
- How are registration activities progressing over time?
- How actively is the CRM system being utilized?

## Dashboard Design

The dashboards use a consistent visual identity to make navigation and interpretation easier.

The design focuses on:

- KPI cards for high-level performance
- Interactive slicers and filters
- Trend analysis
- Breakdown by business dimensions
- Detailed tables for drill-down analysis
- Consistent dashboard layout
- Clear comparison between actual, budget, and forecast figures

---

## Data Privacy

The dashboards shown in this repository are portfolio versions.

Sensitive information, including selected employee names, customer information, project details, and financial figures, has been hidden or anonymized where appropriate.

The source data and original Power BI files are not publicly shared.
